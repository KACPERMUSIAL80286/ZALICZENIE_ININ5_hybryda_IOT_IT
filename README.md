# Zaliczenie przedmiotu - zarządzanie projektem wdrożeniowym

## Opis projektu
Projekt „Przewodnik po stolicach Europy” polega na stworzeniu strony internetowej
prezentującej wybrane stolice europejskie. Każda stolica posiada osobną podstronę
z podstawowymi informacjami, opisem oraz zdjęciem miasta.

## Zakres funkcjonalny
- Wyświetlanie informacji o wybranych stolicach Europy
- Opis miast, ciekawostki i podstawowe dane
- Prezentacja zdjęć miast
- Publikacja strony w internecie za pomocą GitHub Pages

## Wykorzystane technologie
- HTML
- CSS
- Git
- GitHub
- GitHub Pages
