# CONTRIBUTING

Dziękujemy za zainteresowanie współpracą przy projekcie
„Przewodnik po stolicach Europy”.

Poniżej przedstawiono zasady obowiązujące osoby chcące dołączyć do projektu.

## Zasady współpracy
-Każda nowa funkcjonalność lub poprawka powinna być realizowana w osobnym branchu
-Zmiany należy zgłaszać poprzez Pull Request
-Kod powinien być czytelny i zgodny ze strukturą projektu

## Nazewnictwo branchy
Branch powinien być tworzony na podstawie gałęzi `main` i nazwany według schematu:

-`feature/nazwa-funkcjonalnosci`
-`fix/opis-poprawki`

Przykłady:
-`feature/strona-berlin`
-`fix/poprawa-stylow-css`

## Zasady commitów
Commity powinny być krótkie, czytelne i opisowe.
Zalecany schemat:

-`Dodano opis stolicy Berlina`
-`Poprawiono styl nagłówków`
-`Zaktualizowano README`

Commity powinny być pisane w języku polskim.

## Komunikacja
-Komunikacja zespołu odbywa się poprzez komentarze w GitHub
-Wszystkie istotne informacje dotyczące zmian należy umieszczać w Pull Requestach
-W przypadku problemów zalecany jest kontakt poprzez sekcję Issues
